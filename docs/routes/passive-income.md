> 这一类路线 **LetsMigrate 没有收录**，是 RUN 根据各国政府页面和律所、机构 2026 年公开资料补充的。门槛多与当地最低工资或社会指数挂钩，各领馆执行口径不同，递交前请向所属领馆确认。

## 和数字游民签证怎么选

| | 被动收入居留 | 数字游民签证 |
|---|---|---|
| 收入来源 | 养老金、租金、股息、利息、存款 | 境外雇主工资或客户收入 |
| 能否工作 | ❌ 一般不能（含远程） | ✅ 只能为境外雇主/客户工作 |
| 典型门槛 | 葡萄牙 D7 €920/月；西班牙 NLV €2,400/月 | 葡萄牙 €3,680/月；西班牙 €2,442/月 |
| 适合 | 退休、半退休、有资产收益的家庭 | 在职的远程员工、自由职业者 |

> [!WARNING]
> 拿着被动收入签证偷偷远程上班，续签时一查银行流水就可能露馅；工资收入应走数字游民签证。
