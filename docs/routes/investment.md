## 三个必须分清的概念

| | 是什么 | 投资能否直接得到 |
|---|---|---|
| **居留许可** | 合法住在该国的许可 | ✅ 多数投资项目给的是这个 |
| **永久居留** | 无限期居住，通常仍需满足条件 | 塞浦路斯、马耳他 MPRP 直接给；其他需住满年限 |
| **国籍/护照** | 成为该国公民 | 欧盟内**已无**投资直接入籍；入籍要真实居住 + 语言 + 融入 |

另外，**税务居民**是第四个独立问题：拿了身份不住，通常不会成为当地税务居民；住了超过 183 天，往往就是了。

## 中国申请人特别注意

- **资金出境**：中国个人每年 5 万美元购汇额度，大额投资需合规路径，务必提前咨询银行和专业人士，切勿通过地下钱庄。
- **资金来源证明**：所有项目都会做反洗钱尽调，需能说明资金合法来源（工资、经营所得、房产出售等）。
- **双重国籍**：中国国籍法不承认双重国籍，自愿取得外国国籍即自动丧失中国国籍。
