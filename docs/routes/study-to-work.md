# 🎓 留学 → 工作 → 移民

**对中国学生最成熟的一条路**：在当地读书 → 毕业后拿"找工作签证" → 转工作签证/蓝卡 → 永居 → 入籍

[🏠 首页](../../README.md) ｜ [🧑‍💻 技术工作与蓝卡](skilled-work.md) ｜ [🧭 选路线](choose-route.md)

</div>

> [!TIP]
> 很多国家允许**本国院校毕业生**（个别国家也包括全球名校毕业生）在毕业后留下来找工作，期间可以自由打工，找到工作后转技术工作签证时往往还能**免除薪资门槛的一部分或劳动力市场测试**。这一段时间在部分国家还计入永居年限。

```mermaid
flowchart LR
    A[🎓 学生签证] --> B[📄 毕业找工作签证<br>6–36 个月]
    B --> C[🧑‍💻 工作签证 / 欧盟蓝卡]
    C --> D[🏠 永居]
    D --> E[🛂 入籍]
```

## 📊 欧洲各国毕业后找工作签证

| 国家 | 名称 | 期限 | 要点 |
|---|---|---|---|
| 🇩🇪 [德国](../europe/germany.md) | 毕业找工作居留 | **18 个月** | 本硕相同；期间可自由工作；找到对口工作可转蓝卡，B1 德语 21 个月永居 |
| 🇫🇮 [芬兰](../europe/finland.md) | 找工作/创业居留 | **最长 2 年** | 不需 offer；毕业后 5 年内都可申请；有芬兰学历的永居快速通道 |
| 🇮🇪 [爱尔兰](../europe/ireland.md) | Stamp 1G（第三级毕业生计划） | 本科 **12 个月**，硕博 **24 个月** | 毕业 6 个月内申请；转 Critical Skills 应届门槛 EUR 36,848 |
| 🇩🇰 [丹麦](../europe/denmark.md) | 找工作居留 | 2026-10-01 前申请学签者**最长 3 年**；之后申请者**最长 1 年** | 规则刚变，以 SIRI 为准 |
| 🇳🇱 [荷兰](../europe/netherlands.md) | Orientation Year（找工作年） | **12 个月** | 荷兰院校或**全球排名前列大学**毕业 3 年内均可申请；转 HSM 享受 EUR 3,122/月降低门槛 |
| 🇫🇷 [法国](../europe/france.md) | APS 临时居留 | **12 个月**（硕士可续） | 转工作须与专业相关，月薪约 EUR 2,800 以上 |
| 🇸🇪 [瑞典](../europe/sweden.md) | 找工作/创业居留 | **12 个月**（博士 12–18 个月） | 须在学签到期前申请；2026-06 起转身份须至少读完两个学期 |
| 🇦🇹 [奥地利](../europe/austria.md) | 毕业找工作居留 | **12 个月** | 之后转红白红卡 |
| 🇮🇹 [意大利](../europe/italy.md) | 毕业求职/创业居留 | **12 个月** | |
| 🇪🇸 [西班牙](../europe/spain.md) | 毕业求职居留 | **12 个月**（部分资料称 24） | 以领馆/UGE 当年口径为准 |
| 🇬🇧 [英国](../europe/united-kingdom.md) | Graduate 签证 | 现为 2 年；**2027-01-01 起 18 个月**（博士 3 年） | 不能续，需转 Skilled Worker；名校毕业生还可看 HPI |
| 🇨🇭 [瑞士](../europe/switzerland.md) | 毕业找工作 | **6 个月** | 第三国国民工作许可仍受配额限制 |

<sub>表中多数数据来自院校和留学服务机构的公开整理，并已与瑞典移民局、Study in Denmark、Migri 等官方页面交叉核对；比利时、捷克、波兰、波罗的海国家等的找工作期限（一般 9–12 个月）尚未逐一核实，申请前请查各国移民局。</sub>

## ✅ 给中国学生的建议

1. **选校时就想好毕业后的路**：德国（公立大学几乎免学费 + 18 个月 + 蓝卡）、芬兰（2 年）、爱尔兰（英语 + 硕士 2 年）、荷兰（英语授课多 + 找工作年）性价比最高。
2. **学签期间的打工经历和语言**会直接影响毕业后的求职和永居（德国 B1、芬兰语言快速入籍）。
3. **找工作签证一般不能续**，倒计时开始后要尽早转工作签证。
4. 读书期间是否计入永居/入籍年限各国规则不同（如芬兰、丹麦的本国学历可缩短永居或入籍年限），规划时单独核对。
