## 🧑‍💻 F-1 留学 → OPT → H-1B

![类型](https://img.shields.io/badge/%E7%B1%BB%E5%9E%8B-%E6%8A%80%E6%9C%AF%E5%B7%A5%E4%BD%9C-0f766e) ![状态](https://img.shields.io/badge/%E7%8A%B6%E6%80%81-%E5%BC%80%E6%94%BE-2ea44f)

> **最常见的路径：读书 → 实习工作 → 抽签拿工作签证 → 雇主办绿卡。**

<table>
<tr><td width="33%" valign="top"><sub>OPT</sub><br><b>毕业后 1 年，STEM 专业共 3 年</b></td><td width="33%" valign="top"><sub>H-1B 抽签</sub><br><b>2026-02 起按工资等级加权（Level IV 4 次机会）</b></td><td width="33%" valign="top"><sub>FY2027 名额</sub><br><b>已满</b></td></tr>
<tr><td width="33%" valign="top"><sub>10 万美元附加费</sub><br><b>2026-09-30 被法院禁止执行，政府上诉中</b></td><td width="33%" valign="top"><sub>期限</sub><br><b>3 年 + 3 年</b></td><td width="33%" valign="top"></td></tr>
</table>

<table><tr>
<td width="50%" valign="top">✅ <b>适合</b><ul><li>在美读 STEM 硕博</li><li>能拿到较高工资等级 offer</li></ul></td>
<td width="50%" valign="top">❌ <b>不适合</b><ul><li>工资处于 Level I</li><li>人在境外首次申请（附加费风险）</li></ul></td>
</tr></table>

### 🗺️ 申请流程

```mermaid
flowchart LR
  s0["① F-1 读书"]
  s1["② OPT 工作"]
  s2["③ 雇主注册 H-1B 抽签"]
  s3["④ 中签后递交 I-129"]
  s4["⑤ 雇主办 PERM + I-140"]
  s0 --> s1 --> s2 --> s3 --> s4
```

1. **F-1 读书**
2. **OPT 工作** — STEM 可延至 3 年
3. **雇主注册 H-1B 抽签** — 每年 3 月
4. **中签后递交 I-129**
5. **雇主办 PERM + I-140** — 转绿卡

> [!WARNING]
> **注意**
> - F-1 境内转 H-1B 不适用 10 万美元附加费

## 🧑‍💻 EB-1A 杰出人才 / EB-2 NIW 国家利益豁免

![类型](https://img.shields.io/badge/%E7%B1%BB%E5%9E%8B-%E6%8A%80%E6%9C%AF%E5%B7%A5%E4%BD%9C-0f766e) ![状态](https://img.shields.io/badge/%E7%8A%B6%E6%80%81-%E5%BC%80%E6%94%BE-2ea44f)

> **不需要雇主，自己申请绿卡；科研人员和高成就专业人士的主要途径。**

<table>
<tr><td width="33%" valign="top"><sub>EB-1A 中国排期</sub><br><b>FAD 2023-08-01（2026-11）</b></td><td width="33%" valign="top"><sub>EB-2 中国排期</sub><br><b>FAD 2021-10-01；递交日期 2023-01-01</b></td><td width="33%" valign="top"><sub>雇主</sub><br><b>不需要</b></td></tr>
<tr><td width="33%" valign="top"><sub>证明</sub><br><b>EB-1A 领域顶尖；NIW 对美国有国家利益</b></td><td width="33%" valign="top"></td><td width="33%" valign="top"></td></tr>
</table>

<table><tr>
<td width="50%" valign="top">✅ <b>适合</b><ul><li>论文、专利、奖项、媒体报道丰富的人</li></ul></td>
<td width="50%" valign="top">❌ <b>不适合</b><ul><li>指望很快拿绿卡的中国出生申请人</li></ul></td>
</tr></table>

### 🗺️ 申请流程

```mermaid
flowchart LR
  s0["① 整理成就证据"]
  s1["② 递交 I-140"]
  s2["③ 等待排期"]
  s3["④ I-485 或领馆办理"]
  s0 --> s1 --> s2 --> s3
```

1. **整理成就证据** — 论文引用、推荐信、奖项
2. **递交 I-140** — 可加急
3. **等待排期** — 看 Visa Bulletin
4. **I-485 或领馆办理**

> [!WARNING]
> **注意**
> - NIW 不能降级到 EB-3（需 PERM）
> - '金卡'本质也是 EB-1/NIW，同样受中国排期约束

![类型](https://img.shields.io/badge/%E7%B1%BB%E5%9E%8B-%E6%8A%95%E8%B5%84%E5%B1%85%E7%95%99-b45309) ![状态](https://img.shields.io/badge/%E7%8A%B6%E6%80%81-%E5%BC%80%E6%94%BE-2ea44f)

<table>
<tr><td width="33%" valign="top"><sub>TEA 区域</sub><br><b>USD 800,000</b></td><td width="33%" valign="top"><sub>非 TEA</sub><br><b>USD 1,050,000</b></td><td width="33%" valign="top"><sub>额外费用</sub><br><b>区域中心费约 USD 80,000 + 律师费 2.5–3.5 万</b></td></tr>

<table><tr>
<td width="50%" valign="top">✅ <b>适合</b><ul><li>资金充足、来源清晰</li></ul></td>

</tr></table>

### 🗺️ 申请流程

```mermaid
flowchart LR
  s0["① 选项目（区域中心）"]
  s1["② 资金出境并投资"]
  s2["③ 递交 I-526E"]
  s3["④ 条件绿卡"]
  s4["⑤ 2 年后 I-829 去条件"]
  s0 --> s1 --> s2 --> s3 --> s4
```

> **注意**

## 📖 深度解读

### 一句话判断

最大的科技和学术市场，但**排期是中国大陆出生申请人的最大障碍**：职业移民绿卡按出生地排队，EB-2/NIW 中国 Final Action Date 仍停在 2021 年。H-1B 已改为**按工资加权抽签**，"10 万美元附加费"目前被法院阻止执行。

### 主要路线

| 路线 | 要点 | 现状（2026-10） |
|---|---|---|
| **F-1 留学 → OPT → H-1B** | 最常见路径；STEM 专业 OPT 共 3 年 | H-1B 2026-02-27 起按工资等级加权抽签（Level IV 4 次机会 … Level I 1 次）；FY2027 名额已满 |
| H-1B "10 万美元费" | 2025-09-19 总统公告，针对境外受益人 | 2026-09-30 加州联邦法院禁止执行，政府已上诉；另有 DHS 提议的新费用尚未生效 |
| **EB-1A 杰出人才** | 自行申请，无需雇主；证明在领域内顶尖 | 中国 FAD 2023-08-01（2026-11 排期表） |
| **EB-2 NIW 国家利益豁免** | 硕士/杰出能力 + 对美国有国家利益，无需雇主 | 中国 FAD 2021-10-01，Dates for Filing 2023-01-01 |
| **O-1 杰出人才工作签证** | 非移民，可续，常与 EB-1A 配合 | 无排期 |
| **EB-5 投资移民** | TEA 地区 USD 800,000 / 非 TEA 1,050,000，另有区域中心费、律师费 | 2027-01-01 按通胀调整（预计 TEA 约 90 万+）；乡村预留名额可绕开中国排期 |
| "金卡"（Gold Card） | 个人 USD 100 万 / 企业 200 万 + USD 15,000 手续费，本质上是 EB-1/EB-2 NIW 的加速证据 | 截至 2026 年中仅 1 例获批，**仍受中国排期约束**，有诉讼待决 |
| E-2 条约投资者 | — | **中国公民不适用** |

### 入籍与税务

- 绿卡满 5 年（与美国公民结婚 3 年）可申请入籍。
- **绿卡持有人和公民都需就全球收入向美国报税**，这是很多人忽略的长期成本。
