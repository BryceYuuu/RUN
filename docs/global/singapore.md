## 📖 深度解读

| 路线 | 要点 |
|---|---|
| **Employment Pass（EP）** | 2026 年新申请最低月薪 **SGD 5,600**（金融业 6,200），随年龄递增至 45 岁以上 SGD 10,700（11,800）；只计固定月薪；还须通过 **COMPASS 积分 ≥40 分**（月薪 ≥ SGD 22,500 豁免）；雇主须先在 MyCareersFuture 发布 14 天招聘 |
| 2027 年起 | EP 门槛升至 SGD 6,000（金融业 6,600），45 岁以上 SGD 11,500 |
| S Pass | 中等技能，门槛更低但有配额 |
| ONE Pass | 月薪 ≥ SGD 30,000 或在艺术、体育、科研等领域杰出，可自由换工作 |
| EntrePass | 有风投、知识产权、孵化器背书的创业者 |
| 永久居民（PR） | 持 EP 工作数年后申请，审批不透明、酌情决定 |

- 个税低、华人社会、英语工作环境；生活成本（尤其租房）很高。
- 新加坡**不允许双重国籍**。
