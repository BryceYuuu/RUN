## 1. 海牙认证（附加证明书 Apostille）

- **中国自 2023-11-07 起正式加入《取消外国公文书认证要求的公约》**。中国内地出具的公文书（公证书、无犯罪记录公证、学历公证等），在缔约国使用时，可由外交部或授权的地方外办出具**附加证明书**，不再需要"外交部认证 + 使馆认证"的双认证。
- 但**接收国仍可以有自己的要求**：特定有效期、指定翻译类型（宣誓翻译、认证翻译）、原件格式、本地递交流程。正确的问题永远是："这个国家这条路线的办案人员接受什么格式？"
- 部分非缔约国（或对中国加入提出异议的国家）仍需领事认证，递交前查官方清单。

## 2. 核心文件清单

| 类别 | 示例 | 常见要求 |
|---|---|---|
| 身份 | 护照、旧护照、照片、居留历史 | 护照有效期通常须超出签证/居留期 3 个月以上 |
| 民事状态 | 结婚证、出生证明、离婚判决、监护权证明 | 公证 + 附加证明书 + 翻译；家属申请最容易卡在这里 |
| 无犯罪记录 | 公安机关出具的无犯罪记录证明（再办公证） | 多数国家要求 3–6 个月内签发；居住过 >6–12 个月的其他国家也可能要 |
| 学历 | 学位证、毕业证、成绩单 | 学信网认证、目标国学历评估（德国 anabin/ZAB、意大利 CIMEA、荷兰 Nuffic 等） |
| 工作与收入 | 劳动合同、在职证明、工资单、银行流水、个税记录 | 数字游民签证尤其看**连续 3–6 个月**的收入流水 |
| 公司 | 营业执照、股东名册、审计报告、纳税申报、客户合同、发票 | 自雇/创业/投资路线 |
| 住房与保险 | 租约、房产证明、邀请函、医疗保险 | 很多国家要求覆盖当地且保额达标，旅行险常不被接受 |

## 3. 实务顺序

| 步骤 | 动作 |
|---|---|
| 1 | 选定目标路线，**下载官方最新清单**（不要只看中介清单） |
| 2 | 逐项标记：哪些中国文件需要公证、附加证明书、翻译 |
| 3 | 核对有效期窗口：无犯罪记录、银行流水、保险、户籍类文件 |
| 4 | **统一姓名拼写**：护照、学历、合同、银行、家庭文件中的拼音必须一致（含多音字、曾用名） |
| 5 | 原件、扫描件、翻译件、附加证明书页、快递单号放在同一个文件夹（建议同时做云端备份） |
| 6 | 倒推时间：开无犯罪 + 公证 + 附加证明书 + 翻译通常要 2–6 周，再加使馆预约等待 |

## 4. 资金合规

- 个人每年便利化购汇额度 **5 万美元**等值；大额投资、购房需走合规渠道（如 ODI 境外投资备案等），并保留完整的资金来源证据链。
- 所有投资移民项目都有反洗钱尽调：工资积累、经营分红、房产出售、继承等来源都要能举证。

## 5. 国籍

- **中国不承认双重国籍**：定居外国、自愿加入外国国籍的，自动丧失中国国籍。拿永久居留不影响国籍，入籍才影响。
- 入籍前想清楚：国内房产、社保、继承、出入境（之后需办中国签证）等连带问题。
