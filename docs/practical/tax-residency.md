## 四个互相独立的问题

| 问题 | 由什么决定 |
|---|---|
| 我能不能合法住在这里？ | 签证 / 居留许可 |
| 我是不是这里的税务居民？ | 当地税法：停留天数、住所、生活重心、家庭所在地 |
| 我的雇主会不会因此在当地产生税务义务？ | 常设机构（PE）规则、工资代扣、社保 |
| 我原来的国家还要不要对我征税？ | 原居住国税法 + 双边税收协定 |

## 常见的税务居民触发标准

| 国家 | 触发条件（简化） |
|---|---|
| 大多数欧洲国家 | 一个日历年或任意 12 个月内停留 **>183 天**，或在当地有惯常住所/生活重心 |
| 🇬🇷 希腊 | 任意滚动 12 个月内 >183 天，**从第一天起**算税务居民 |
| 🇨🇾 塞浦路斯 | >183 天，或满足"60 天规则" |
| 🇨🇭 瑞士 | 有工作连续 30 天、无工作 90 天即可能构成 |
| 🇮🇸 冰岛 | 12 个月内 ≥6 个月 |
| 🇹🇭 泰国 | 一年 >180 天，汇入的境外收入可能征税 |
| 🇺🇸 美国 | 绿卡持有人和公民**无论住在哪都要就全球收入报税** |

## 中国税务居民身份

- 中国个人所得税法：在中国境内有住所，或无住所而一个纳税年度内在境内居住**累计满 183 天**的个人，为居民个人，就全球所得纳税。
- 户籍在中国的人一般被视为"在中国境内有住所"。出国后如何认定、如何避免双重征税，需结合税收协定和专业意见。
- CRS（共同申报准则）下，各国金融机构会交换账户信息。

## 常见的特殊税制（以当地最新规定为准）

| 国家 | 制度 | 要点 |
|---|---|---|
| 🇵🇹 葡萄牙 | NHR 已于 2024 废止 → IFICI | 范围大幅收窄 |
| 🇪🇸 西班牙 | Article 93（贝克汉姆法） | 2023 起扩展到合格远程工作者，需 Form 149 申请 |
| 🇮🇹 意大利 | 新居民统一税 | 境外收入每年缴固定税额，2026 预算法后迁入为 EUR 300,000 |
| 🇬🇷 希腊 | Article 5C | 迁入专业人士所得税优惠 |
| 🇳🇱 荷兰 | 30% ruling | 外籍高技术人才部分工资免税，比例逐步下调 |
| 🇭🇷 克罗地亚 / 🇲🇪 黑山 | 数字游民境外收入免税 | 仅限符合条件的境外雇佣收入 |
| 🇨🇾 塞浦路斯 / 🇲🇹 马耳他 | non-dom / 汇入制 | 需专业规划 |
