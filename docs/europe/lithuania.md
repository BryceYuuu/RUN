> [!TIP]
> **一句话判断**：欧盟 + 申根 + 欧元区。**没有数字游民签证**。**2024-07-01 起几乎所有在立陶宛工作的外国人都需立陶宛临时居留许可**（免签、申根签、他国居留都不能再用来工作）。技术工作看**就业居留 vs 欧盟蓝卡**（EUR 3,617/月），创业看 **Startup Visa**（专家评审通过后可免资本和雇员要求）。

## 📖 深度解读

### 路线要点

### 就业居留 vs 欧盟蓝卡（以 2025 年平均月薪 EUR 2,411.40 计）
| | 就业居留 | 欧盟蓝卡 |
|---|---|---|
| 薪资 | 视岗位 | 标准 **约 EUR 3,615–3,617/月**（1.5 倍，站内两处数据略有差异）；高附加值紧缺职业 **EUR 2,893.68/月**（1.2 倍） |
| 就业服务局决定 | 可能需要 | 月薪 < 3 倍平均工资（**EUR 7,234.20**）时可能需要，除非属紧缺清单或续签豁免 |
| 审理 | 最长 4 个月（加急 2 个月） | **1 个月**（加急 15 天） |
| 国家费用 | EUR 220（加急 440） | EUR 220（加急 440） |
| 有效期 | 一般最长 2 年 | **3 年**，或合同期 + 3 个月 |
| 换雇主 | 需在签新合同前 ≥3 个月向移民局申请 | 前 2 年需移民局决定；第 3 年起更灵活 |
| 失业风险 | 失业可能导致撤销 | 连续失业 >3 个月或有效期内失业不止一次可能撤卡 |

- 蓝卡资质：高等教育，或 5 年同等经验；ICT 管理/专家可凭近 7 年内 3 年经验。
- 2025-01-01 起就业服务局只为季节工和部分外派员工发工作许可，普通长期就业以移民局居留许可为核心。
- **永久居留**：连续合法居住 5 年 + 立陶宛语和宪法知识考试；蓝卡可累计欧盟内 5 年（至少 2 年在立陶宛）。

### Startup Visa
- **初创企业定义**：有创新增长潜力的微型/小型企业，注册不超过 5 年；创始团队一般不超过 4 人。
- **流程**：向 Startup Lithuania / 创新署提交申请（创新性、团队、资金、资质、商业计划）→ 专家评审通过并出具确认 → 经 MIGRIS 系统递交居留（30 个国家可通过 VFS 递交）。
- 获批后**免除**一般商业居留的部分资本和雇员要求。
- **期限**：首次 2 年，可续 3 年。
- 居住面积：每位成年人 ≥7 平方米。
- 税务：2026 年起企业所得税标准税率 17%，小微企业可享 7%（部分情形首两个纳税期 0%）；个人营业执照年收入上限 EUR 50,000。
