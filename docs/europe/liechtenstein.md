## 📖 深度解读

### 路线要点
- **旅游**：最长 3 个月（按入境规则），不得居住或工作。
- **EEA 公民**：工作居留和无工作居留都受年度配额限制，部分类别靠抽签。
- **第三国国民**：一般需要强有力的锚点（列支敦士登雇主、家庭担保人等），门槛很高。
- **无营利活动居留**：有单独路线，但名额少、条件多（充足资源、医保、无本地营利活动），不是数字游民许可。
- **申请顺序**：区分国籍类别 → 区分目的 → 查配额 → 雇主/担保人材料 → 资金、住房、保险 → 向移民和护照办公室申请。
- 永久居留需按国籍、许可类型和居住历史核查，语言和融入常是决定因素。
