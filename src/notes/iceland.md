## 一句话判断

EEA + 申根，**非欧盟**。**旧的"远程工作长期签证"已在 2026 年 5 月被废止**，网上老攻略已失效。现行"短期居留许可"只适用于探亲、艺术家、科学家、运动员访问等，**不允许普通远程工作**，也不通永居。对中国远程工作者来说，冰岛目前**没有可用的数字游民路线**。

## 路线要点

### 短期居留许可（2026 新框架）
| 项目 | 规则 |
|---|---|
| 停留 | >90 天且 ≤180 天 |
| 频次 | 任意 12 个月内一次 |
| 目的 | 探访近亲；以艺术家、科学家、运动员身份访问等 |
| 工作 | **不得工作**（少数列明豁免除外） |
| 生活资金 | 个人 **ISK 259,951/月**；已婚夫妇 ISK 415,922/月 |
| 保险 | 健康和意外险，保额 ≥ ISK 2,000,000 |
| 费用 | ISK 12,200 |
| 递交 | 纸质原件邮寄或投放到移民局（Dalvegur 18, Kópavogur） |
| 续签/永居 | **不能续签，不通永居** |

- 2026-05-13：签证服务移交外交部，《外国人法》长期签证条款废止。
- **税务**：12 个月内停留 ≥6 个月 → 从抵达日起成为税务居民，全球收入纳税。
