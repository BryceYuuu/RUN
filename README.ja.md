# RUN · 润

**中国本土のパスポート保有者のための移住ハンドブック**です。ヨーロッパ 36 か国（99 の移民ルート）と、ヨーロッパ以外の 13 の目的地を扱っています：デジタルノマドビザ、技能就労と EU ブルーカード、起業と自営業のルート、投資による居住。

- 最終更新は **2026 年 11 月 3 日** です。ヨーロッパ編は、[LetsMigrate.org](https://letsmigrate.org/en/countries/) の各国のページ、プログラムの記録、ガイドをもとに再構成して書き直したもので、それぞれ公式の情報源と照合しています（`data/programmes.json` に 378 件の公式リンク）。
- グローバル編（アメリカ、カナダ、オーストラリア、ニュージーランド、日本、韓国、シンガポール、香港、フィリピン、タイ、マレーシア、UAE、ラテンアメリカ）は、政府と第三者の情報源からまとめたもので、検証の厳密さはヨーロッパ編より劣ります。
- コンテンツは簡体字中国語で書かれています。構造化データは [`data/programmes.csv`](data/programmes.csv) にあります。

> **法律、税務、移民に関する助言ではありません。** ルールは絶えず変わります。必ず政府の公式 Web サイトで確認してください。
